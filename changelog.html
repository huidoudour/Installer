功能总结

  • 重构Kotlin + Jetpack Compose 全面迁移 — 项目整体由 Java/XML 迁移至 Kotlin + Compose (Material3)，UI 组件与界面全面重写
  • 新功能独立终端模块 lib-terminal — 基于 PTY 的终端模拟，支持滚动回看、管道输入、字符宽度处理、Shizuku 会话开关及 TermuxBridge 联动
  • 新功能APK 签名校验体系 — 智能授权安装流程 + 完整签名校验与签名比对机制，安装前可识别同源/异源包
  • 新功能应用内更新检测 — 新版本检测与提示（仅正式包启用），并新增应用内更新日志页面
  • 新功能预测性返回手势 — 全局返回动画容器、叠加页面返回遮罩、低版本降级兼容
  • 新功能MD3 加载动画 — 安装进度加载动画及多种动画模式切换
  • 新功能降级安装支持 — 版本关系判定与降级安装选项
  • 新功能高级设置与实验室页面 — 安装行为选项持久化、安装参数设置、实验性功能入口
  • 新功能开源许可页面 — 依赖许可清单自动生成与展示
  • 优化安装器/请求者包名选择 — 统一包名选择对话框、按安装状态选择授权、Shizuku 与 Dhizuku 特权安装开关分离
  • 优化Shell 功能增强 — 输出搜索、保存输出到 Download、历史命令对话框、快速滚动、15 个新增快捷命令
  • 优化日志管理 — 全局日志集成、安装流程记录、日志管理界面
  • 优化构建与发布 — Baseline Profile 与启动基准测试模块、GitHub Actions 工作流优化、Dependabot 自动依赖更新、AGP 升级至 9.5.0
  • 修复Dhizuku 安装与权限回调 — 修复 DhizukuAPI 安装问题、权限状态更新和回调处理
  • 修复语言切换与终端修复 — 修复语言切换 bug 及过渡动画；修复 shell 页面 bug、终端输入焦点与 IME 事件处理
  • 国际化Android 13+ 系统级应用语言切换 — 接入 per-app language API，语言设置与系统同步
